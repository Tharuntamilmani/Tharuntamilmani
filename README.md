## Current Work

### Universal Log Pre-Processing Framework — ULPF

A modular cybersecurity data-processing framework designed to transform **heterogeneous security and network logs into standardized, traceable events**.

The system is being engineered as a layered pipeline covering:

* **Ingestion** — accepting heterogeneous log sources and formats
* **Parsing** — extensible parser engine and registry
* **Normalization** — conversion into a universal event representation
* **Persistence** — raw-event storage and integrity/trace tracking
* **Integration** — REST APIs, OpenSearch and SIEM/Data Lake workflows
* **Tooling** — management console and Parser Studio
* **Validation** — synthetic datasets, integration tests and contract validation

I’m also exploring **Ollama-powered local AI capabilities** as an optional intelligence layer for unknown-log analysis, parser assistance, malformed-event analysis, summarization, and natural-language querying — while keeping the core processing pipeline **deterministic and schema-driven**.
